# Laboratório de Rede com SNMP
**Visão Geral do Projeto**
- Este repositório contém scripts e ferramentas para realizar o monitoramento de dispositivos de rede por meio do protocolo SNMP (Simple Network Management Protocol). O foco é a coleta e análise de dados de dispositivos de rede, com o objetivo de otimizar o gerenciamento e o desempenho da rede. O desenvolvimento e os testes foram realizados no Packet Tracer.
