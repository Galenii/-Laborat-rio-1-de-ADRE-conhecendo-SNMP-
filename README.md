# Laboratório 
**Sobre o Projeto**
- Este repositório contém ferramentas e scripts para o monitoramento de atividades utilizando o protocolo SNMP (Simple Network Management Protocol). O objetivo é coletar e analisar métricas de dispositivos de rede, garantindo um gerenciamento mais eficiente e melhor desempenho. O projeto foi desenvolvido e testado no Packet Tracer.
